## 1. 만세력 계산 방식 (검증 완료)

| 항목 | 방식 | 검증 |
|---|---|---|
| 음력 → 양력 | 한국 음양력 대조표 1930~2030 내장 (윤달 포함) | 한국천문연구원 데이터 기반 라이브러리와 4,364건 전수 일치 |
| 연주 | **입춘(立春) 절입 시각** 기준, 입춘 전 출생은 전년도 간지 | 절입 ±1일 경계 356건 일치 |
| 월주 | 12절(節) 입절 시각 기준 (소한=축월 … 대설=자월) | 24절기 시각을 태양 황경(겉보기)으로 독립 계산해 대조 |
| 일주 | JDN(율리우스 적일) 기반 60갑자 — `(JDN+49) mod 60` | 2000-01-01 = 戊午 등 기준값 일치 |
| 시간(時干) | 오서둔법(五鼠遁法) | 12시진 전수 일치 |
| 월간(月干) | 오호둔법(五虎遁法) | 12개월 전수 일치 |
| 대운 | 양남·음녀 순행 / 음남·양녀 역행, 3일=1년으로 대운수 산출 | — |
| 절기 데이터 | ephem(태양 겉보기 황경) + 장동(nutation) + 광행차 보정, KST 변환 | 2024·2026 춘분·하지가 천문대 값과 1분 이내 일치 |
| 격국 | 월지 지장간 투출(本氣→中氣→餘氣) 십성으로 판정, 록·양인지 여부로 건록/양인/월겁 구분 | — |
| 십이운성 | 일간별 장생지 + 양간 순행·음간 역행 | — |

`js/data-calendar.js` 는 파생 데이터이므로 직접 수정하지 말고, 연도 범위를 늘리려면 같은 형식으로 재생성하십시오.

### 계산 규약 (중요)
- 모든 시각은 **KST(UTC+9) 고정**으로 계산합니다. 브라우저 시간대·서머타임과 무관하게 같은 결과가 나옵니다.
- **자시(23:00 이후) 출생은 일주를 다음 날로** 봅니다(자시 일주설). 화면에도 안내 문구가 표시됩니다.
- 시간을 모를 경우 시주를 비우고 3주(년·월·일)로만 풀이합니다.
- 진태양시(경도) 보정과 1954~1961년 UTC+8:30, 1948~1960년 서머타임은 반영하지 않았습니다.

## 2. 해석 구조 (v3)

- **무료 요약**: 60갑자 일주론 → 월겁/건록격 → 겉과 속 → 오행 균형 → 십성 재주 → 재물 그릇 → 배우자궁(십이운성) → 건강 → 2026 세운 → **피할 달·잡아야 할 달** → 신살 → 오늘의 처방. 약 1,600자.
- **프리미엄 13장**: 표지(사주 4주 인장) · ① 명의 첫인상 ② 겉과 속(오해 세 가지) ③ 기질 심층 ④ 십성 지도(강점·그림자) ⑤ 재물(통로 3곳·새는 구멍·계좌 처방) ⑥ 일과 사업 ⑦ 인연(배우자상·시기) ⑧ 인간관계(반복 갈등·올해 조심할 사람) ⑨ 건강 ⑩ 2026 월별 길흉(핵심 4개월 상세) ⑪ 대운 ⑫ 살풀이 처방(7일 처방·부적) ⑬ 신살·공망. 약 9,600자.
- **타로**: 정/역방향 + 카테고리(연애·재물·직장·오늘)별 해석, 위치 프레임, 카드 사이를 잇는 브리지 문장, 심층 상징, 카드별 행동 제안, 세 장을 하나로 묶는 종합.

## 3. 결제 연동

`js/payment.js` 상단 `CONFIG.provider` 하나만 바꾸면 됩니다.

```js
const CONFIG = {
  provider: 'demo',        // 'demo' | 'ctee' | 'transfer' | 'portone' | 'toss'
  transfer: { bank: '', account: '', holder: '', minutes: 60, confirmCode: '' },
  ctee:     { report: '', talisman: '', vip: '' },
  portone:  { storeId: '', channelKey: '', payMethod: 'CARD' },
  toss:     { clientKey: '', method: '카드' }
};
```

- `demo` — 결제창 없이 승인 시뮬레이션(현재 기본값, 「테스트 결제」 배지 표시).
- `ctee` — 크티 판매 링크로 이동. **키 발급·카드 등록 없이 바로 판매 가능한 경로.**
- `transfer` — 계좌이체. 입금 계좌·예금주·기한을 보여 주고 주문을 `awaiting_transfer`로 저장합니다.
  입금 확인 후 구매자에게 알려 준 `confirmCode`를 입력하면 열립니다(수동 확인 방식).
- `portone` / `toss` — 결제창 호출. 키 미설정 시 자동으로 데모로 대체.

> **승인 검증은 반드시 서버에서 하십시오.** 클라이언트 코드는 결제창 호출까지만 담당합니다.
> 포트원 `GET /payments/{paymentId}` 또는 토스 결제조회 API로 금액을 확인하고 리포트를 발급해야 합니다.

상품: 9,900원 정밀 리포트 / 14,900원 개운 부적 4종 / 29,900원 VIP 패키지.
결제 완료 기록은 `localStorage`(`salpuri_orders_v1`)에 남고, 잠금 해제된 리포트는 새로고침 후에도 유지됩니다.

## 4. 화면 구성

- **오프닝**: Canvas 안개 + 3겹 구름 장막 + 금박 커튼. 좁은 인앱 브라우저에서도 버튼과 겹치지 않는 흐름 배치(면책 문구는 본문 푸터에만 표기).
- **히어로 3컷 스토리**: 이미지·자막 크로스페이드 + 내레이션(BGM 0.55→0.25 덕킹). 이미지 위에는 어떤 버튼도 올리지 않습니다.
- **점사 의식**: 명식 계산·타로 3장 선택 후 약 2초간 전체 화면에서 촛불·태극 인장과 단계 문구가 흐른 뒤 결과가 스르륵 열립니다.
- **사주 만세력**: 4기둥(십성·지장간·십이운성) · 오행 레이더 · 강약 게이지 · 용신 · 격국/십성 지도 · 무료 풀이 · 2026 세운(잡을 달/피할 달) · 대운.
- **신비 타로**: 카테고리 선택 → 부채꼴 22장 중 3장 → 카드가 슬롯으로 날아가 3D 플립 + 금빛 파동 → 점사 의식 → 이야기형 해석.
- **부적·리포트**: 상품 3종 · **부적 4종 갤러리(미리보기·다운로드)** · 결제 모달(방식별) · 13장 리포트 · 인쇄/PDF.
- **공유**: 결과 카드 하단·푸터의 텍스트 영역 버튼만 사용. `navigator.share` 지원 시 네이티브 공유 시트, 미지원 시 링크 복사 + 토스트.
