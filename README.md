# 살풀이 : 천기(天機) — 정밀 사주 · 타로 · 프리미엄 리포트

`saju-site/` 는 상용 판매를 전제로 만든 사주·타로 웹앱입니다. 빌드 도구 없이 정적 파일만으로 동작하므로
`index.html` 을 웹서버에 올리면 바로 서비스됩니다.

```
saju-site/
├── index.html            화면 구조 (구름 장막 오프닝 · 탭 · 입력 · 명식 · 타로 · 상품)
├── css/style.css         전체 스타일 (다크 골드·버건디 테마, 반응형, 인쇄용 PDF 스타일)
├── audio/
│   ├── bgm.mp3           배경음악 루프 ("Eastern Thought" — Kevin MacLeod, CC BY 3.0)
│   └── narration-1~3.mp3 히어로 3컷 여성 내레이션 (ElevenLabs 'Saju Husky V3 Warm' · -16.5 LUFS)
├── fortune-teller.jpg    히어로 1컷 — 촛불 아래 타로 카드
├── fortune-teller-2.jpg  히어로 2컷 — 금박 카드·명리 두루마리
├── fortune-teller-3.jpg  히어로 3컷 — 달빛 신당의 붉은 실·부적
├── js/
│   ├── data-calendar.js  음양력 대조표(1930~2030) + 24절기 시각(KST)
│   ├── saju-engine.js    만세력 계산 엔진 (사주 4기둥·십성·용신·대운·세운·신살)
│   ├── saju-text.js      해석문 생성 (무료 요약 + 프리미엄 10개 장)
│   ├── tarot.js          메이저 아르카나 22장 데이터 + 인라인 SVG 일러스트
│   ├── payment.js        포트원 V2 / 토스페이먼츠 / 크티(ctee) 결제 모듈
│   └── app.js            화면 제어 (안개·사운드·3컷 스토리·탭·타로·결제 흐름)
└── README.md
```

## 1. 만세력 계산 방식 (검증 완료)

| 항목 | 방식 | 검증 |
|---|---|---|
| 음력 → 양력 | 한국 음양력 대조표 1930~2030 내장 (윤달 포함) | 한국천문연구원 데이터 기반 라이브러리와 4,364건 전수 일치 |
| 연주 | **입춘(立春) 절입 시각** 기준, 입춘 전 출생은 전년도 간지 | 절입 ±1일 경계 356건 일치 |
| 월주 | 12절(節) 입절 시각 기준 (소한=축월 … 대설=자월) | 24절기 시각을 태양 황경(겉보기)으로 독립 계산해 대조 |
| 일주 | JDN(율리우스 적일) 기반 60갑자 — `(JDN+49) mod 60` | 1983-07-10 = 己亥 등 기준값 일치 |
| 시간(時干) | 오서둔법(五鼠遁法) | 12시진 전수 일치 |
| 월간(月干) | 오호둔법(五虎遁法) | 12개월 전수 일치 |
| 대운 | 양남·음녀 순행 / 음남·양녀 역행, 3일=1년으로 대운수 산출 | — |
| 절기 데이터 | ephem(태양 겉보기 황경) + 장동(nutation) + 광행차 보정, KST 변환 | 2024·2026 춘분·하지가 천문대 값과 1분 이내 일치 |

`js/data-calendar.js` 는 파생 데이터이므로 직접 수정하지 말고, 연도 범위를 늘리려면 같은 형식으로 재생성하십시오.
(`LUNAR_TABLE` = `[양력설날 년,월,일, 윤달월, [각 달 일수…]]`, `SOLAR_TERMS[년]` = 1월 1일 0시 KST부터 흐른 분)

### 계산 규약 (중요)
- 모든 시각은 **KST(UTC+9) 고정**으로 계산합니다. 브라우저 시간대·서머타임과 무관하게 같은 결과가 나옵니다.
- **자시(23:00 이후) 출생은 일주를 다음 날로** 봅니다(자시 일주설). 화면에도 안내 문구가 표시됩니다.
- 시간을 모를 경우 시주를 비우고 3주(년·월·일)로만 풀이합니다.
- 진태양시(경도) 보정과 1954~1961년 UTC+8:30, 1948~1960년 서머타임은 반영하지 않았습니다.
  필요하면 `analyze()` 입력에 보정 분을 더하는 방식으로 확장할 수 있습니다.

## 2. 결제 연동

`js/payment.js` 상단 `CONFIG` 만 바꾸면 됩니다.

```js
const CONFIG = {
  mode: 'demo',           // 'demo' | 'portone' | 'toss' | 'ctee'
  portone: { storeId: 'store-...', channelKey: 'channel-key-...', payMethod: 'CARD' },
  toss:    { clientKey: 'test_ck_...', method: '카드' },
  ctee:    { report: 'https://ctee.kr/...', talisman: '...', vip: '...' }
};
```

- `demo` — 결제창 없이 승인 시뮬레이션. 현재 기본값이며 화면에 「테스트 결제」 배지가 표시됩니다.
- `portone` — 포트원 V2 브라우저 SDK(`PortOne.requestPayment`) 결제창 호출. 키 미설정/차단 시 자동으로 데모로 대체.
- `toss` — 토스페이먼츠 표준결제(`TossPayments(clientKey).requestPayment`), 성공 시 `?payment=success` 로 복귀.
- `ctee` — 크티 판매 링크로 이동(키 발급 없이 판매 가능).

> **승인 검증은 반드시 서버에서 하십시오.** 클라이언트 코드는 결제창 호출까지만 담당합니다.
> 포트원 `GET /payments/{paymentId}` 또는 토스 결제조회 API로 금액을 확인하고 리포트를 발급해야 합니다.

상품: 9,900원 정밀 리포트 / 14,900원 개운 부적 배경화면 / 29,900원 VIP 패키지.
결제 완료 기록은 `localStorage`(`salpuri_orders_v1`)에 남고, 잠금 해제된 리포트는 새로고침 후에도 유지됩니다.

## 3. 화면 구성

- **오프닝**: Canvas 안개 + 3겹 구름 장막(`#cloudVeil`)이 입장 클릭 시 좌우로 걷히고, 좌우 금박 커튼이 걷히며 캐릭터 등장.
- **히어로 3컷 스토리**: 입장 후 컷1→2→3 이미지·자막 크로스페이드 + 여성 내레이션 재생(BGM 0.55→0.25 덕킹, `1·2·3` 인디케이터로 다시 듣기).
  배경음악은 `audio/bgm.mp3`(115초, 128kbps, -18 LUFS 루프)를 `<audio loop>`로 재생하며 입장 시 0→0.55로 페이드인, 우측 상단 토글과 연동.
- **사주 만세력**: 이름·성별·양/음력(윤달)·생년월일·12시진(모름) 입력 → 4기둥(한자·한글·오행 색상), 십성·지장간,
  오행 레이더·비율, 신강신약 게이지, 용신·희신·기신, 무료 요약, 2026 세운, 대운 9구간.
- **신비 타로**: 카테고리(연애·재물·직장/사업·오늘의 운) 선택 → 부채꼴 22장 중 3장 선택 → 3D 플립 → 과거·현재·미래 해석 + 종합.
- **부적·리포트**: 상품 3종 + 결제 모달 + 결제 후 10개 장 프리미엄 리포트(2026 월별 표·대운 표) 열람,
  인쇄 → PDF 저장 지원(`@media print`).

## 4. 로컬 확인

```bash
cd saju-site
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

콘솔 에러 0건, 1280×800 / 390×844 / 768×1024 에서 동작 확인했습니다.
