## 1. 만세력 계산 방식 (검증 완료)

| 항목 | 방식 | 검증 |
|---|---|---|
| 음력 → 양력 | 한국 음양력 대조표 1930~2030 내장 (윤달 포함) | 한국천문연구원 데이터 기반 라이브러리와 4,364건 전수 일치 |
| 연주 | **입춘(立春) 절입 시각** 기준, 입춘 전 출생은 전년도 간지 | 절입 ±1일 경계 356건 일치 |
| 월주 | 12절(節) 입절 시각 기준 (소한=축월 … 대설=자월) | 24절기 시각을 태양 황경(겉보기)으로 독립 계산해 대조 |
| 일주 | JDN(율리우스 적일) 기반 60갑자 — `(JDN+49) mod 60` | 2000-01-01 = 戊午 등 기준값 일치 |
| 시간(時干) | 오서둔법(五鼠遁法) | 12시진 전수 일치 |
| 월간(月干) | 오호둔법(五虎遁法) | 12개월 전수 일치 |
| 대운 | 양남·음녀 순행 / 음남·양녀 역행, 3일=1년으로 대운수 산출 | — |
| 절기 데이터 | ephem(태양 겉보기 황경) + 장동(nutation) + 광행차 보정, KST 변환 | 2024·2026 춘분·하지가 천문대 값과 1분 이내 일치 |
| 격국 | 월지 지장간 투출(本氣→中氣→餘氣) 십성으로 판정, 록·양인지 여부로 건록/양인/월겁 구분 | — |
| 십이운성 | 일간별 장생지 + 양간 순행·음간 역행 | — |

`js/data-calendar.js` 는 파생 데이터이므로 직접 수정하지 말고, 연도 범위를 늘리려면 같은 형식으로 재생성하십시오.

### 계산 규약 (중요)
- 모든 시각은 **KST(UTC+9) 고정**으로 계산합니다. 브라우저 시간대·서머타임과 무관하게 같은 결과가 나옵니다.
- **자시(23:00 이후) 출생은 일주를 다음 날로** 봅니다(자시 일주설). 화면에도 안내 문구가 표시됩니다.
- 시간을 모를 경우 시주를 비우고 3주(년·월·일)로만 풀이합니다.
- 진태양시(경도) 보정과 1954~1961년 UTC+8:30, 1948~1960년 서머타임은 반영하지 않았습니다.

## 2. 해석 구조 (v3)

- **무료 요약**: 60갑자 일주론 → 월겁/건록격 → 겉과 속 → 오행 균형 → 십성 재주 → 재물 그릇 → 배우자궁(십이운성) → 건강 → 올해 세운 → **피할 달·잡아야 할 달** → 신살 → 오늘의 처방. 약 1,600자.
- **프리미엄 리포트 10쪽**: 표지(사주 4주 인장) · ① 명의 첫인상 ② 겉과 속(오해 세 가지) ③ 기질 심층 ④ 십성 지도(강점·그림자) ⑤ 재물(통로 3곳·새는 구멍·계좌 처방) ⑥ 일과 사업 ⑦ 인연(배우자상·시기) ⑧ 인간관계(반복 갈등·올해 조심할 사람) ⑨ 건강 ⑩ 올해 월별 길흉(핵심 4개월 상세) ⑪ 대운 ⑫ 살풀이 처방(7일 처방·부적) ⑬ 신살·공망 · 올해 달력 · 내년 달력. 약 11,000자.
- **정밀 궁합**: 두 사람의 만세력을 각각 뽑아 일간 합·충, 배우자궁(일지)의 육합·삼합·반합·충·형·파·해, 오행 상보(누가 무엇을 몇 % 들고 있는지), 올해 세운까지 겹쳐 봅니다. 케미 점수(64~98) + 네 축(감정·생활·보완·올해) + 정밀 풀이 4장. 관계 유형(썸·연인·부부·친구·동업)에 따라 총평과 처방이 달라집니다.
- **외모·점(외모·점 탭 · 구 개운)**: 키·몸무게를 선택 입력하면 사주의 신강·신약, 오행 편중, 용신·기신으로 **충전형(찌워야 트이는 사주) / 감량형(비워야 도는 사주) / 균형형**을 판별하고, BMI 21~22 기준 표준체중에 사주 보정 계수(토·수 편중, 일간 강약)를 적용해 **하한선·목표 구간·정체선 kg**을 계산합니다. 실루엣 비교 도해 + kg 게이지, 헤어 두상 도해(이마 개방·감쌈), 얼굴·손·목 도해에 **살릴 점(吉) 4곳과 뺄 점(凶) 4곳**을 좌표·라벨과 함께 표시하고, 십성 구조로 목소리·속도·어미와 "이렇게 말하면 손해 / 이렇게 바꾸면 붙는다" 3쌍을 제시합니다. 마지막에 지갑 색·향·침대 머리 방향을 정리합니다.
- **확장 메뉴 5종** (모두 같은 만세력 엔진 기반 · 사주 탭에서 입력한 명식을 그대로 재사용): **① 신살·귀인** 도화·역마·화개·홍염·백호·괴강 + 천을·문창·학당·월덕·천덕을 실제 규칙으로 판별해 기둥 위치와 쓰는 법까지 · **② 오늘의 운세** 오늘(KST) 일진의 합·충·형과 십성으로 점수·재물/대인/건강·잡을 시간·피할 시간·행운 색·방향·숫자 · **③ 신년 12개월** 절기 월건 12개 막대 그래프 + 잡을 달/피할 달 + 분기별 조언 · **④ 재물·적성** 사업형/직장형 비율, 돈이 모이는 구조, 동업·투자 주의점, 재물이 트이는 대운 · **⑤ 택일** 이사·개업·계약·결혼 × 이번 달/다음 달/60일에서 육합·천을귀인·용신일을 가산해 길일 Top 5와 피할 날(무난 미만은 Top에서 제외).
- **타로**: 정/역방향 + 카테고리(연애·재물·직장·오늘)별 해석, 위치 프레임, 카드 사이를 잇는 브리지 문장, 심층 상징, 카드별 행동 제안, 세 장을 하나로 묶는 종합.

## 3. 결제 연동

`js/payment.js` 상단 `CONFIG.provider` 하나만 바꾸면 됩니다.

```js
const CONFIG = {
  provider: 'demo',        // 'demo' | 'ctee' | 'transfer' | 'portone' | 'toss'
  transfer: { bank: '', account: '', holder: '', minutes: 60, confirmCode: '' },
  ctee:     { report: '', talisman: '', vip: '' },
  portone:  { storeId: '', channelKey: '', payMethod: 'CARD' },
  toss:     { clientKey: '', method: '카드' }
};
```

- `demo` — 결제창 없이 승인 시뮬레이션(현재 기본값, 「테스트 결제」 배지 표시).
- `ctee` — 크티 판매 링크로 이동. **키 발급·카드 등록 없이 바로 판매 가능한 경로.**
- `transfer` — 계좌이체. 입금 계좌·예금주·기한을 보여 주고 주문을 `awaiting_transfer`로 저장합니다.
  입금 확인 후 구매자에게 알려 준 `confirmCode`를 입력하면 열립니다(수동 확인 방식).
- `portone` / `toss` — 결제창 호출. 키 미설정 시 자동으로 데모로 대체.

> **승인 검증은 반드시 서버에서 하십시오.** 클라이언트 코드는 결제창 호출까지만 담당합니다.
> 포트원 `GET /payments/{paymentId}` 또는 토스 결제조회 API로 금액을 확인하고 리포트를 발급해야 합니다.

상품: 9,900원 정밀 리포트 / **17,900원 2인 동반 패키지(정가 19,800원 · 1인당 8,950원 · 서로 다른 명식 2개)** / 14,900원 개운 부적 4종 / 29,900원 VIP 패키지 / **29,000원 개명·작명 후보 5선(정가 39,000원 · 오픈 특가)**.
결제 완료 기록은 `localStorage`(`salpuri_orders_v1`)에 남고, 잠금 해제된 리포트는 새로고침 후에도 유지됩니다.

## 4. 화면 구성

- **오픈 기념 한정 팝업**: 입장 직후 `sessionStorage` 기준 세션당 1회, 다크·골드 모달(배지·제목·본문·[확인]·우측 상단 ✕). 관리자 프리패스에서는 뜨지 않고, 이벤트 종료일(2026-11-28) 이후에는 자동으로 표시되지 않습니다.
- **오프닝**: Canvas 안개 + 3겹 구름 장막 + 금박 커튼. 좁은 인앱 브라우저에서도 버튼과 겹치지 않는 흐름 배치(면책 문구는 본문 푸터에만 표기).
- **히어로 3컷 스토리**: 이미지·자막 크로스페이드 + 내레이션(BGM 0.55→0.25 덕킹). 이미지 위에는 어떤 버튼도 올리지 않습니다.
- **점사 의식**: 명식 계산·타로 3장 선택 후 약 2초간 전체 화면에서 촛불·태극 인장과 단계 문구가 흐른 뒤 결과가 스르륵 열립니다.
- **사주 만세력**: 4기둥(십성·지장간·십이운성) · 오행 레이더 · 강약 게이지 · 용신 · 격국/십성 지도 · 무료 풀이(쉬운 말 사전 포함) · 올해 세운(잡을 달/피할 달) · 대운.
- **v11 쉬운 말·배지**: 모든 풀이문의 명리 용어를 `내 편 기운(비겁)`·`돈·결과물 기운(재성)`처럼 쉬운 말(원래 이름) 순서로 표기하고, `비견`을 `비겁`으로 오해하지 않게 명식 표 아래 안내와 접이식 사전을 넣었습니다. `신년` 탭은 **올해 + 내년 12개월 달력**(연도는 해마다 자동 갱신)을 배지(🎯 대박·🌱 좋음·🌿 무난·⚠️ 조심·🚨 위험)와 `이 달엔 챙길 것 / 피할 것` 한 줄로 보여 주고, `궁합` 탭에는 재미 코너 **💘 배우자 한눈팔 확률(12~88%)** 카드가 있습니다.
- **탭 12개**: 사주 · 아이사주 · 궁합 · 오늘 · 신살 · 신년 · 재물 · 택일 · **외모·점** · 작명 · 타로 · 부적. 한 번 입력한 생년월일시를 사주·궁합·확장 메뉴·작명이 공유합니다. 모바일은 5칸씩 여러 줄 그리드로 12개가 한눈에 보이며 문서 가로 넘침은 0px입니다.
- **신비 타로**: 카테고리 선택 → 부채꼴 22장 중 3장 → 카드가 슬롯으로 날아가 3D 플립 + 금빛 파동 → 점사 의식 → 이야기형 해석.
- **부적·리포트**: 상품 4종(정밀 리포트 · **2인 동반 패키지** · 부적 4종 · VIP) · **부적 4종 갤러리(미리보기·다운로드)** · 결제 모달(방식별, 1인권 결제 시 **+8,000원 2인 업그레이드** 원클릭) · 10쪽 리포트(올해·내년 달력) · **[PDF 파일 바로 저장]**(인쇄창 없이 실제 .pdf 다운로드) · 인쇄 보조.
- **👯 2인 동반 패키지**: 결제자는 서로 다른 명식 2개까지 사주 리포트·10쪽 PDF가 열립니다(명식 지문 = 이름+양력 생년월일+성별, `localStorage.salpuri_duo_charts_v1`). 리포트 카드에 `👯 2인 패키지 이용 중 (n/2명 등록)`이 뜨고 ✕로 등록을 바꿀 수 있습니다. 3번째 명식은 9,900원 1인권 안내. 1인권·부적·VIP 결제자와 관리자 프리패스는 인원 제한이 없습니다.
- **🔥 소름 돋아요**: 두 곳에 같은 버튼이 있고 숫자는 하나입니다. ① **탭바 바로 아래에 붙박이로 고정된 상단 배지**(`지금까지 N명이 소름 돋아요` · 스크롤해도 항상 보임) ② **결과 맨 마지막의 큰 오렌지·골드 버튼**(`🔥 소름 돋아요 · N`, 사주는 결과 맨 끝 카드, 나머지 메뉴는 공유 버튼 바로 아래). 숫자는 **우리 Apps Script + Google Sheet(`sooreum` 시트)** 가 전 세계 방문자 공유로 셉니다(`GET ?action=sooreum` 읽기 · `POST {type:'sooreum_hit'}` 증가, `apps-script/sooreum.gs`). 첫 화면에는 마지막 확인값(없으면 이관 시작값 6)이 바로 떠서 `—` 가 보이지 않고, 서버 응답이 오면 그 값으로 맞춰집니다. 통신이 막히면 localStorage에만 기록하는 폴백 + 4초 뒤 1회 자동 재시도를 씁니다. 중복 도배 방지를 위해 브라우저당 1회(`localStorage`)로 제한하며, 두 버튼이 그 1회를 함께 씁니다(한쪽을 누르면 다른 쪽도 '소름 돋았습니다'로 바뀝니다).
- **외모·점 바로 보기**: 탭을 누르면 사주 탭에서 명식을 먼저 돌리지 않았어도 지금 입력된 기본 명식으로 즉시 계산해 체형·목표 kg·살릴 점·뺄 점을 첫 화면에 펼칩니다. 상단 키·몸무게 칸을 고치면 0.4초 뒤 자동 재계산됩니다. 작명 탭도 같은 방식으로 사주 선행 없이 진단이 열립니다.
- **공유**: 결과 카드 하단·푸터의 텍스트 영역 버튼만 사용. `navigator.share` 지원 시 네이티브 공유 시트, 미지원 시 링크 복사 + 토스트.
